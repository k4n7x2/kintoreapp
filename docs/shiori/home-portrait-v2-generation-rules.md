# 朝倉栞｜ホーム立ち絵v2 制作時の統一ルール

> **ユーザー選定**：位置合わせは画像ごとの眼・顎の厳密な機械座標ではなく、**画像制作時の参照と構図の指示**で統一する。  
> **規格の段階**：制作ルールの方針確定・PR #38で草案管理中。完成素材の採用／アプリ本番切替は別判断。  
> 主参照：[私服5枚のパスとSHA](home-portrait-v2-private-reference-family.json)／[v2機械可読規格](home-portrait-standard-v2.json)。

## 1. 目的と適用範囲

このルールは**ホーム画面用1086×1448の近接通常頭身立ち絵**（衣装差分・表情差分）に適用する。SD・イベント一枚絵・設定画・背景は対象外。旧正式v1（941×1672）の画像を勝手に改変・廃止しない。

狙うのは**ホーム画面で栞の顔の大きさと距離感が変わらず、表情が自然に変化すること**。目や顎の位置を完全固定することではない。

## 2. 実画像の参照優先順位

1. **構図・顔の見かけの大きさ・距離感**：私服`normal` を代表に、既存私服5表情（`normal / thinking / surprised / smile / playful`）を**一組として**実画像参照する。
2. **表情の変え方**：同じ5枚の該当表情を参照する。目の開き・眉・口・頬・八重歯・自然な顎の変形を認める。
3. **栞の顔立ち・髪・瞳の人物同一性**：GitHub正式`shiori-master-v1.jpg`を優先する。
4. **画風・光・透明感**：正式`shiori-style-fullbody-v1.jpg`、**体型**：正式`shiori-character-sheet-v1.jpg`。
5. **衣装**：対象衣装の採用済み資料や依頼時に指定された服。私服5枚を引用したからといって私服の衣装を他シーンに強制しない。

GitHubに画像があるだけでは画像制作ツールへ入力できた証明にならない。プロジェクト添付の実体と対象版を検査し、ツール入力の成否を制作時に別記する。入力できない場合は人物を想像で補完しない。

## 3. 制作時に守る3つのルール

### A. 画角・姿勢の連続性を優先

- 私服5枚と同程度の近接感・頭部の見かけの大きさ・顔の向き・カメラ距離を維持する。
- 同じ衣装・同じポーズで表情だけ変える場合、**髪のボリューム・花飾り・肩・身体の向き・手の位置・衣服の形・光の方向を原則維持**する。
- ただし髪の自然な動きや表情筋の変化まで一切禁止しない。「全画像でピクセル完全一致」を求めない。
- 衣装差分では服のシルエットだけ自然に変わる。頭部や体型を衣装に合わせて縮めない。

### B. 表情は自然に変わってよい

- **変化可**：眉、上下まぶた、目の開口、視線、頬、口角、口の開き、歯・八重歯、軽い顎輪郭の変化。
- **注意**：顔の向き・頭全体が表情の切替だけで不自然に跳ねないようにする。
- `surprised` の開眼、`smile` の口・頬、`playful` の視線変化を、**眼中点や顎先の固定座標に戻すよう修正しない**。
- 首・頭を意図的に動かす演出は、通常の同一ポーズ表情差分とは区別し、別ポーズとして管理する。

### C. 画像の技術仕様は固定

- キャンバス**1086×1448px**、制作原本は背景透過PNG（実アルファ）。白塗り背景・市松模様・UI文字は不可。
- 登録用は原本とは別のコピーを**ロッシーWebP品質85**に変換し、透過と寸法を維持する。
- 近接構図の自然な見切れは許容。ただし顔、髪飾り、指、顎などが不自然に切れたり、画面内で下端が一直線に見えたりしないようにする。
- 毛先は`visual.md`の健康的で滑らかなまとまりを優先し、過剰な散り毛・枝毛を避ける。

## 4. 制作依頼に使用する共通指示文（文章テンプレート）

以下のテンプレートは**文章としての仕様**であり、このファイルを読む行為自体は画像制作の許可ではない。画像制作・編集はユーザーが明示的に「生成」と依頼した場合にのみ行う。

```text
顔・髪・瞳の人物同一性は正式shiori-master-v1、
画風と光はshiori-style-fullbody-v1、体型はshiori-character-sheet-v1を優先。

人物外周は構図として自然な見切れにし、髪の枝毛・手指崩れ・アルファ縁の残留を防ぐ。

```

## 5. 出力後の品質検査

**自動検査は技術品質だけ**：画像ファイルの実形式、1086×1448px、実アルファ、透明画素・可視画素、画像デコード可否。これに成功しても**人物の似ている／表情が自然／頭位置が合っているとは宣言しない**。

**目視検査を別に実施**：私服5枚と並べて、顔の見かけの大きさ・構図・人物同一性・髪／花飾り・衣装・姿勢の継続性・表情の魅力・自然な切れ・明暗背景での透過縁を確認。同一Android表示領域での表情切替チェックはアプリ採用前の別工程。

**廃止する機械合否**：両眼中点X/Y±6px、両眼間距離±2%、顎±8px、特定座標への平行移動補正。STEP 2〜STEP 5の数値は**監査履歴として保管**し、今後の基準値には使わない。

**技術検査の合格≠立ち絵の正式採用**。採用／GitHub登録／アプリ組込み／Android実機確認を別々に記録する。
