# 朝倉栞｜ホーム立ち絵v2 基準を「私服5枚」に変更（ユーザー決定）

> **適用**：2026-10-20。現在の参照先は[5枚の実ファイル一覧・SHA-256](home-portrait-v2-private-reference-family.json)。基準セットの**選定はユーザー決定済み**、画素座標の**規格校正・全画像適合・本番切替は未完了**。PR #38で提案管理中、main未反映。

## 1. この変更の意味

**現行の参照セット＝私服5表情を一組として使う。** 5枚が「どの程度表情を変えてよいか」を示し、`normal` をニュートラル時の配置・顔の大きさ・向きの代表とする。ただし、`normal`の眼・口・顎のピクセル座標を他の表情へ**強制一致させない**。眼・口・眉・頬・自然な顎変化は表情依存とする。

ユーザーが前に選んだジム用 `smile-alt1` は**過去の構図マスターの由来資料**としてハッシュを保存するが、今後の規格判定の一次参照にしない。STEP 2〜STEP 5の「ジムsmile基準」の数値・結果は**測定時点の履歴**として保持し、現行基準への合否判定に転用しない。

## 2. 新しい基準セット（元ファイルのまま使用）

| 役割 | 表情 | 固定される実ファイル |
|---|---|---|
| 配置・距離感の代表 | normal | `public/assets/shiori/home/v2/shiori-private-home-normal-r1.webp` |
| 表情の自然な幅 | thinking | `public/assets/shiori/home/v2/shiori-private-home-thinking-r1.webp` |

| 遊び心の表現 | playful | `public/assets/shiori/home/v2/shiori-private-home-playful-r1.webp` |

5枚すべて**1086×1448・実アルファ付きWebP**で、以前のGitHub `main` `f7148b56734f76faef386c97b4482c9c3e2f3508` に実在することを比較監査で確認。各バイトハッシュはJSONへ固定した。今回、画像そのものの再圧縮・移動・修正・生成は行っていない。

**参照上の役割は別**：栞の同一人物性＝`shiori-master-v1.jpg`、塗り＝`shiori-style-fullbody-v1.jpg`、体型＝`shiori-character-sheet-v1.jpg`。私服5枚への切替はこれらの正式参照を廃止しない。また衣装を別の服にする場合、私服の布の形状までコピペを義務化しない。

## 3. 表情変化を許容する検査方針

### 揃えるもの（頭部・画角）
- 縦横ピクセル寸法 **1086×1448**、透過、アプリの共通CSSでの顔の見かけの大きさ・構図
- 眉や口の変化とは無関係な髪の大局的な輪郭、耳の根元、花飾りの付け根などの**安定しやすい複数点**（髪の流れや花飾りの描き直しによる変化があれば慎重に扱う）
- カメラ距離・頭の傾き・身体の自然な比率、同一ポーズでの肩・手の連続性

### 動いてよいもの（表情）
- まぶたの上・下、眉毛、視線・瞳の向き、頬、口角、歯・八重歯、開口幅
- 驚きや笑顔に伴う下顎の自然な変化（**顎先を不変アンカーとして自動判定しない**）

**NG例**：驚きの開眼で上下まぶた中点が10px動いた、という理由だけで不合格とする。**確認すべきこと**：耳・花飾り・非表情領域の頭部がまとめて同じ方向に動いているか、表情変化で説明できるか。

## 4. 過去の座標候補・検査器との互換

- STEP 5の[再注釈監査](home-portrait-v2-step5-review.md)は、旧基準`gym/smile`との比較に限る一次目視測定。**新基準セットの5枚を正式な座標合格と認定した結果ではない**。
- 旧v2 JSONにあった「ジムsmile基準の眼中心(425,447)/(585,355)・顎(594,587)」は、現在の`geometry.legacyGymSmileUncalibrated`へ退避した。**現行`geometry.anchors`は空**。未校正なので合格を出さない。
- 新しい`check_home_portrait_v2.py`は寸法・アルファ等の基本検査が可能だが、**実用の顔アンカー基準が空なので現時点で正式PASSを出せない**。旧来の「眼中点±6px／顎±8px」を私服五表情の自然な表情変化に機械適用しない。
- `private-v2`はアプリの**衣装ID**、`home-portrait-v2-trial`は**立ち絵の制作規格名**。名称を混同しない。

## 5. 次の判定プロセス

1. 私服5枚を**互いに比較**し、表情差分領域をマスクして、表情によらない耳・髪・花飾り・頭部外周の安定度を測る。固定点候補は**後から独立レビューで確定**させる。最初に一枚の眼・顎へ値を合わせない。
2. 得られた固定点の位置ばらつきと測定誤差から、実装可能な許容値を提案。無理に±6pxを維持しない。
3. ジム5表情を**私服5枚の構図系に対する比較対象**として検査し直す。表情の開閉や口の動きをずれとして罰しない。
4. Androidで同一ビューポート・同一CSS条件で切替試験した後に、ユーザー承認を得て正式な規格へ移行する。

**今は画像編集・CSS変更・規格`calibrated`への昇格・mainマージをしない。**
