# 朝倉栞｜ホーム立ち絵v2 基準を「私服5枚」に変更（ユーザー決定）

> **適用**：2026-10-20。現在の参照先は[5枚の実ファイル一覧・SHA-256](home-portrait-v2-private-reference-family.json)。基準セットの**選定はユーザー決定済み**、**制作時の共通ルールは選定済み、技術・目視／Androidの最終検品と本番切替は未完了**。PR #38で提案管理中、main未反映。

## 1. この変更の意味

**現行の参照セット＝私服5表情を一組として使う。** 5枚が「どの程度表情を変えてよいか」を示し、`normal` をニュートラル時の配置・顔の大きさ・向きの代表とする。ただし、`normal`の眼・口・顎のピクセル座標を他の表情へ**強制一致させない**。眼・口・眉・頬・自然な顎変化は表情依存とする。

ユーザーが前に選んだジム用 `smile-alt1` は**過去の構図マスターの由来資料**としてハッシュを保存するが、今後の規格判定の一次参照にしない。STEP 2〜STEP 5の「ジムsmile基準」の数値・結果は**測定時点の履歴**として保持し、現行基準への合否判定に転用しない。

## 2. 新しい基準セット（元ファイルのまま使用）

| 役割 | 表情 | 固定される実ファイル |
|---|---|---|
| 配置・距離感の代表 | normal | `public/assets/shiori/home/v2/shiori-private-home-normal-r1.webp` |
| 表情の自然な幅 | thinking | `public/assets/shiori/home/v2/shiori-private-home-thinking-r1.webp` |
| 目を大きく開く幅 | surprised | `public/assets/shiori/home/v2/shiori-private-home-surprised-r1.webp` |
| 笑顔・八重歯の見せ方 | smile | `public/assets/shiori/home/v2/shiori-private-home-smile-r1.webp` |
| 遊び心の表現 | playful | `public/assets/shiori/home/v2/shiori-private-home-playful-r1.webp` |

5枚すべて**1086×1448・実アルファ付きWebP**で、以前のGitHub `main` `f7148b56734f76faef386c97b4482c9c3e2f3508` に実在することを比較監査で確認。各バイトハッシュはJSONへ固定した。今回、画像そのものの再圧縮・移動・修正・生成は行っていない。

**参照上の役割は別**：栞の同一人物性＝`shiori-master-v1.jpg`、塗り＝`shiori-style-fullbody-v1.jpg`、体型＝`shiori-character-sheet-v1.jpg`。私服5枚への切替はこれらの正式参照を廃止しない。また衣装を別の服にする場合、私服の布の形状までコピペを義務化しない。

## 3. 最終的に選んだ方式：制作時のルール

ユーザーは、表情を変えると目・顎が自然に動くため、**機械的な顔座標計算を今後の制作規格に使わない**方針を選んだ。細部は[制作ルール](home-portrait-v2-generation-rules.md)と[v2制作仕様](home-portrait-standard-v2.md)に整理した。

- **揃える**：1086×1448、顔の見かけの大きさ・カメラ距離・全体構図・髪飾り・同一ポーズの衣装／身体の連続性
- **自由に変えてよい**：目の開き、眉、視線、口、頬、自然な顎輪郭
- **機械検査**：画像の実形式・寸法・アルファ・画像デコード。これだけ合格しても見た目の合格とは宣言しない
- **目視検査**：私服5枚と並べて人物・表情・頭部の自然な連続性を判断
- **製品表示検査**：Androidの同じ画面で表情切替を確認

## 4. STEP 2〜5の位置座標監査

当時のジムsmile単体を基準とする座標値は、**過去の監査ログとして保存するだけ**。新規素材の強制補正、登録前の眼・顎座標による自動合否に再利用しない。

旧v2 JSONにあったジムsmile用の眼・顎座標と許容値は現行作業用の規格から外し、歴史的資料に留める。

`private-v2`はアプリの**衣装ID**、`home-portrait-v2-trial`は**制作規格ID**であり別物。

## 5. 今後の確認作業

1. 制作時の参照画像入力（GitHub上の存在とは別）を確認
2. 出力画像に対して形式・寸法・透過の**自動検査**
3. 私服5枚との目視比較で、表情を犠牲にせず距離感・キャラ性・姿勢の連続性を確認
4. Android実機で表情切替の見え方を確認してから、正式採用や本番切替を判断

**眼・顎の座標を再び精密校正する作業は必要条件にしない**。制作・目視が合格した画像だけを次の工程へ進める。
