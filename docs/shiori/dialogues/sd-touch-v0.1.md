## 目的と操作の区別

| ユーザー操作・きっかけ | 使用するセリフ |
| --- | --- |
| 記録・カレンダー・分析画面へ移動 | 既存の画面別通常セリフ。タップ台本を無条件に使わない |
| 吹き出しをタップ | 既存の画面別通常セリフを再抽選 |
| **SD栞本体をタップ** | この資料の `touch.*` に限定して抽選 |
| SD栞本体を短時間に繰り返しタップ | `touch.repeat` |
| ごくまれな本体タップ | `touch.rare` |
| 記録を保存したとき | 既存の保存結果連動セリフを優先。触れていないのにタップ反応を出さない |

## 表示条件・抽選の試験仕様（未実装）

1. **通常タップ**：`touch.normal` 60%、現在画面に対応する `touch.record` / `touch.calendar` / `touch.analysis` 35%、`touch.rare` 5%。抽選率は試験値で、検証後の変更余地を残す。
2. **連続タップ**：5秒以内に3回以上の本体タップがあった場合に `touch.repeat` を優先。直近タップから8秒以上経過したら通常扱いへ戻す。端末の時刻情報とメモリ内の直近操作だけで判定し、永続的なタップ履歴を作らない。
3. **直前セリフ回避**：同じグループに別の文があれば直前の文を避ける。同一文の連発や各タップでの毎回同じリアクションを抑える。
4. **保存結果の優先**：記録保存後のセリフは画面更新や非同期応答で上書きしない。明示的にSD栞本体をタップした場合はタップ反応に切り替えてよい。
5. **表示**：タップのたびに短い縮小・反発（例：420ms）を検討。強い揺れや発光を避け、`prefers-reduced-motion` に従う。画像・吹き出しの現行位置と固定高さを保つ。
6. **操作領域**：本体タップと吹き出しタップを別操作として扱い、イベント二重発火、スクロール妨害、透明余白の誤タップ、キーボード操作不能を防ぐ。
7. **現行コード**：`public/index.html` の `#character-layer-record` / `#character-layer-history` / `#character-layer-analysis` は現時点で `aria-hidden="true"` の画像レイヤー。現行 `#record-sd-talk` / `#calendar-sd-talk` / `#analysis-sd-talk` は吹き出し操作用。画像レイヤー自体のタップ判定はまだ未実装なので、アプリ開発側がアクセシブルな独立操作面を設計する。
8. **安全なフォールバック**：タップ用データ未読込・取得失敗時は中立的な一言を表示し、記録保存・他画面・既存の画面別セリフは維持する。

## セリフ本文

### `touch.normal` — 通常タップ（12本）

**表示条件**：記録・カレンダー・分析のいずれでも使用。ユーザーがSD栞本体に触れたときの直接反応。

- `touch.normal.01` ん？ 呼んだ？
- `touch.normal.02` あ、どうしたの？
- `touch.normal.03` 何かあった？
- `touch.normal.04` うん、聞いてるよ。
- `touch.normal.05` なに？ ちょうど暇してたところ。
- `touch.normal.06` あ、こっち見てたんだ。
- `touch.normal.07` 少し考えごとしてた。どうしたの？
- `touch.normal.08` ん、ちょっと待って。……はい、どうぞ。
- `touch.normal.09` 呼ばれた気がしたんだけど。
- `touch.normal.10` なあに？
- `touch.normal.11` あ、何か話す？
- `touch.normal.12` ごめん、少しぼーっとしてた。

### `touch.record` — 記録画面専用タップ（4本）

**表示条件**：記録画面でSD栞本体に触れたときのみ。入力済みの実績・状況を断定しない。

- `touch.record.01` 入力、ひと段落した？
- `touch.record.02` どこか確認したいところ、あった？
- `touch.record.03` あ、ごめん。記録、見てた。
- `touch.record.04` 私も数字を比べると、ついじっくり見ちゃう。

### `touch.calendar` — カレンダー画面専用タップ（4本）

**表示条件**：カレンダー画面でSD栞本体に触れたときのみ。実際の予定は断定しない。

- `touch.calendar.01` 予定、決まった？
- `touch.calendar.02` こっちの予定？ まだ考え中。
- `touch.calendar.03` 私、空いてる日を見つけると嬉しくなるんだよね。
- `touch.calendar.04` 何か楽しみな予定でもある？

### `touch.analysis` — 分析画面専用タップ（4本）

**表示条件**：分析画面でSD栞本体に触れたときのみ。実績が上昇したなどとは断定しない。

- `touch.analysis.01` 何か面白い変化、見つけた？
- `touch.analysis.02` こうやって振り返るの、結構好き。
- `touch.analysis.03` ん？ 気になる数字でもあった？
- `touch.analysis.04` 見返してると、あっという間だね。

### `touch.repeat` — 連続タップ（4本）

**表示条件**：短時間の連続タップを検知した場合のみ。最初の1回に対して表示しない。

- `touch.repeat.01` あれ、また呼んだ？
- `touch.repeat.02` ちょっと、反応見てるでしょ。
- `touch.repeat.03` はいはい。ちゃんと聞いてるよ。
- `touch.repeat.04` ……そんなに気になる？

### `touch.rare` — まれなタップ（2本）

**表示条件**：通常の単発タップ時に低確率で表示。関係性の進展・特別な過去や約束を追加しない。

- `touch.rare.01` ……特に用がなくても、呼んでいいよ。
- `touch.rare.02` なんだか、こういうのも悪くないね。
