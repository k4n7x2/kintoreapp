# 朝倉 栞 — ビジュアル・画像生成・素材管理仕様

## 1. 最重要：正式マスター画像

**[reference/shiori-master-v1.jpg](./reference/shiori-master-v1.jpg)**

GitHub実体：`docs/shiori/reference/shiori-master-v1.jpg`
画像形式：JPEG、1536 × 1024 px、4分割の表情資料。

| 配置 | 表情・役割 |
|---|---|
| **左上** | **無邪気な笑顔**：紫の目が生き生きし、八重歯が見える |
| **右上** | **日常の落ち着いた美人顔**：静かな視線、柔らかな口元 |
| **左下** | **いたずらっぽい笑み**：目を少し細め、八重歯がのぞく |
| **右下** | **自然で上品な微笑み**：知的な美人らしさと愛嬌の均衡 |

**この4分割の人物を、同一人物である朝倉栞の正式な顔・画風・表情の基準とする。**
以前生成した他のイラストと違いがあれば、この正式マスターを優先する。
背景、服装、小物、ポーズはシーンに合わせて変更できる。

### 参照の要件

画像生成する場合は、マスター画像を実際に取得・視覚的に確認し、生成・編集の**入力画像として渡す**。
「GitHub上に存在する」「指示文にURLを書く」だけでは参照したことにならない。参照できない場合は未参照であることを明言し、必要に応じてユーザーに添付を求める。
この制約を回避するために、マスターを参照せず「参照した」と主張しない。
**ユーザーが明示的に「生成」と書かない限り画像生成しない。**

## 2. 正式な外見

- **髪：** 肩に触れる程度のダークブラウンのボブ。胸元までのロング案は撤回済み。
- **前髪：** 軽やかなシースルーバング。透けすぎず適度に毛束感を残す。
- **毛先：** 自然な内巻きを主体に、ところどころ軽い外ハネ。
- **質感：** 艶やかだが重くない。顔周りに自然な細い毛束。
- **瞳：** ラベンダー寄りの紫。外周に少し深い色、透明感のある虹彩。
- **目の形：** 少し切れ長の**穏やかなツリ目**。目尻が緩やかに上がる。鋭すぎず猫っぽさを少し含む。
- **顔：** 可愛いより美人寄り。卵型寄りの輪郭、細すぎない顎、わずかな頬の丸み。
- **眉：** 自然で細めのアーチ、眉尻は少し上向き。
- **鼻：** 小ぶりで端正。
- **口：** 口角が少し上がった自然な形。本当に笑うと**小さな八重歯**が見える。
- **体型：** 華奢一辺倒ではなく、健康的ですらりとした女性らしいスタイル。過度な誇張は避ける。
- **身長：** 164cm程度は仮案。厳密な数値は未確定。

### 基本印象

**「真顔は端正な美人、話すと親しみやすく、笑うと急に無邪気になる」**。
目元と口元の微細な変化でいたずらっぽさを出すが、常に誘惑的にはしない。

## 3. 服装の確定方針

- **大学・普段：** 綺麗めカジュアル。ゆったりしたシャツ、カーディガン、ニットなど。
- **お出かけ：** ときどき上品なフェミニンスタイル。
- **自宅：** 細いフレームのメガネ、オーバーサイズのスウェット等、気の抜けた格好。
- **トレーニング：** シンプルで洗練されたスポーツウェア。
- **基本色：** 白、グレー、ネイビー、くすみラベンダー。淡いピンクなどを差し色に。

避ける：過度な肌の露出、誘惑を狙った衣装やポーズ、ギャル風、ロリータ風の過剰装飾、キャラクターを幼くしすぎる表現。

## 4. 表情の指針

1. **通常・微笑み：** 上品で自然。ホーム画面の基本。
2. **いたずら：** 目を少し細め、片側の口角がわずかに上がる。相手の反応を楽しんでいる。小悪魔感2/5。
3. **無邪気：** 心から笑い、目元が柔らかく崩れ、八重歯が見える。最大の魅力。
4. **自宅メガネ：** ゲーム中、少し眠そう／気の抜けた自然体。

**避ける表情：** とろけるような媚びた笑み、過度な流し目、誇張された色気、極端に鋭いツリ目、幼児的な大きすぎる目。
「いたずらっぽい」と「誘惑的」は異なる。

## 5. 画風

- 2Dの日本のアニメ・マンガ風、上質なソーシャルゲームのキャラクター立ち絵
- 繊細な線、透明感のあるラベンダー系の目、落ち着いた彩度、柔らかな光と陰影
- 柔らかくて清潔感があるが、のっぺりした塗りにしない
- 笑顔では上品さを崩しすぎず、自然な表情変化で愛嬌を出す
- **特定の既存作品をそのまま再現するのではなく、オリジナルキャラクターとして一貫させる**

美人らしさを残すことを理由に大人の誘惑的な表情へ寄せない。逆に愛嬌を出すために幼い少女顔へ変えない。

## 6. アプリ用画像の仕様（確定）

- **立ち絵・表情差分：背景透過PNGのみ**
- 実際にアルファチャンネルを持つこと。白背景や市松模様を描いただけでは不可。
- 基本は**ソシャゲのホーム画面風のバストアップ～腰上**。ポーズは自然体。
- 画面端に収めやすく、頭頂部や髪先を不自然に切らない。
- PNGに文字、フキダシ、背景、UIを描き込まない。それらはHTML/CSSで実装する。
- 大きな全身イラスト・背景付き一枚絵・紹介画像は別用途。背景付きの場合はJPEGも可。
- 表示するスマホ画面サイズと通信容量に合わせて、採用後に解像度・圧縮を検討する。
- 新規画像の採用前に**顔の同一性・表情の自然さ・透過・構図・可読性**を確認する。

### 旧素材との整合

現行リポジトリには試作の `public/assets/shiori/standing/training-default.svg` がある。
これは新基準の透過PNGではない。正式なPNGの生成・採用・GitHub登録・画面参照先の更新を確認するまでは、置換済みとみなさない。

## 7. 生成・採用・反映のワークフロー

1. ユーザーが明示的に **「生成」** を依頼。
2. GitHub最新 `main` の本書・[character.md](./character.md)・[dialogue.md](./dialogue.md) を読み、マスターJPEGを実際に生成入力に使う。
3. 指定の服装・表情・構図で画像を生成。立ち絵は透過PNG。
4. マスターと比較し、顔・瞳・髪・画風、PNGのアルファの有無を確認。
5. **ユーザーの採用・保存指示**に基づいて正式名で登録。採用が不明なら勝手に置き換えない。
6. GitHubへの登録結果をファイル実体で確認。必要な場合だけ画面の参照先を修正。
7. デプロイ状態・本番画面での表示を別途確認。「生成」「保存」「表示」を混同しない。

基準画像の更新は旧版を残したまま `shiori-master-v2.jpg` のように世代管理し、ユーザー承認後に [README.md](./README.md) の現行マスター指定を変更する。

## 8. 生成時の指示例（文章だけで完結させない）

> 朝倉栞のホーム画面用、背景完全透過のPNGバストアップ立ち絵。正式マスターの顔立ち・画風を最優先して同一人物として描く。21歳前後の大学生。肩に触れるダークブラウンのボブ、シースルーバング、緩やかなツリ目、ラベンダー系の紫の瞳、小さな八重歯。上品で知的な美人だが、自然体で親しみやすい。自然な微笑み、ほんの少しだけいたずらっぽい目元。綺麗めカジュアルの落ち着いた服装。媚びた笑顔・色気・過剰な露出・頬杖・背景・文字を避ける。ソシャゲのホーム画面でキャラとセリフが共存しやすい余白と構図。

上の例を使う場合も、**必ずマスター画像を実際に添付・参照**すること。
