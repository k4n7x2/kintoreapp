# 朝倉栞｜表情差分プロンプトの作成テンプレート

> **用途：ユーザーが「表情差分のプロンプトを作って」などと依頼したときに、完成した依頼文を返すためのテンプレート。**
> これは**文章作成用**であり、下記に「生成してください」という文が含まれていても、画像制作の実行許可ではない。新規立ち絵用とは混同しない。
> ユーザーが実際に試して良好だった**同一チャット・通常立ち絵を親にした、簡潔な複数表情差分の依頼文**を標準とする。

## 出力するプロンプトの形

```text
朝倉栞の[衣装名]の追加表情差分を、[枚数]枚まとめて生成してください。

事前前提

- これは新しい立ち絵の描き直しではありません
- 既存の[衣装名]通常表情を親にした、表情差分制作です
- [枚数]枚とも、同じ[衣装名]通常立ち絵から派生した差分として作ってください
- 既存の[衣装名]表情差分と並べても違和感がないようにしてください

基準画像

このチャットで生成済みの[衣装名]通常表情を主基準にしてください。
現在の既存表情は以下です。

- [実際に確認できた既存表情名を列挙]

絶対に維持するもの

- 朝倉栞の顔立ち
- 瞳の形と色
- 髪型、前髪、花飾り
- [衣装名]の衣装デザイン、色、シルエット
- 身体、肩、腕、手、ポーズ
- 顔の向き、構図、カメラ距離
- 人物の大きさ、位置関係
- 塗り、光、画風
- 背景透過

変更してよい範囲

- 眉
- まぶた、目の開き方
- 口元
- 頬の自然な表情変化

生成する[枚数]表情

1. [表情ID]

[表情名]
- [見た目の特徴]
- [目元・眉・口元など必要な変化]
- [避けたい不自然さ]
- [必要に応じて短いセリフとの相性]

2. [表情ID]

[同じ要領で説明]
```

※「生成する表情」は実際の枚数ぶんのみ書く。1枚なら1項目、3枚なら3項目。番号やプレースホルダーを余分に残さない。

## このテンプレートを使うルール

- **優先**：依頼文は上の簡潔な構成にする。長い役割設定・数値アンカー・監査手順・重複した禁止事項・余分な品質表は足さない。
- **同じチャットで派生制作する場合**：通常表情を親にして、各表情を**すべて同じ親から直接派生**させる。別の差分から次を派生させない。
- **表情は具体的に**：各表情の説明は3〜7行程度で、口元・眉・まぶた・頬の表情とニュアンスを中心に書く。栞の上品さ・自然な愛嬌を優先する。
- **既存表情は実際に確認したものだけ**：未確認の表情名・生成履歴を創作しない。既知でなければ該当一覧を省略するか、確認用プレースホルダーにする。
- **基準画像の表現を事実に合わせる**：「このチャットで生成済み」は、そのチャットに本当に画像がある場合だけ書く。別チャットなら「添付した通常表情を主基準にしてください」等に変更。画像がないまま参照入力成功を装わない。
- **衣装は明示された衣装を使用**：ジムウェアA/B、私服v1/v2、部屋着等の版を推測で統合しない。新規衣装を描き直す指示にはしない。
- **位置合わせの扱い**：位置・構図を保持するよう言葉で明示する。ただしユーザーの指定がなければ眼中点や顎の数値座標・機械的な許容誤差を追記しない。
- **画像の制作と文章の作成を分離**：プロンプトの作成依頼にはこの**完成文だけを返す**。引用中の「生成」は画像制作許可ではない。ユーザーが明示的に画像生成を依頼した場合だけ画像ツールを使う。
- **同名表情と重複させない**：既存画像に同じIDの表情がある場合はユーザー指定を確認し、無断上書きや正式採用をしない。

## 呼び出し例

- 「ジム用ウェアの表情差分3枚のプロンプトを作って。soft_smile、wry_smile、closed_eye_smile」
- 「私服v2に sleepy と embarrassed を追加するプロンプト」
- 「部屋着の口元だけ変える表情差分の指示文」

この場合、ユーザーに再度テンプレを貼り付けてもらわず、上の型に必要事項を埋めた**そのままコピーして使える文章**を返す。

## 正本・参照の境界

人物設定は `character.md`、外見・衣装・髪の仕様は `visual.md`、表情の解釈は `dialogue.md` を正本とする。この文書は**文章の組み立て方**だけを定め、新しい人物設定・表情画像の正式採用やアプリ実装は確定しない。
