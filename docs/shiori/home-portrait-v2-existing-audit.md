ただし、画像はアプリ表示用 `public/assets/shiori/gim/v1/` に登録されているのであって、`docs/shiori/reference/` の正式な「構図参照版」としての登録、または画像ツールへ実際に参照入力できた証拠ではない。正式な新規格の採用とも区別する。新規に同じ画像を作り直す理由はない。

**算定方法**：顔の概算矩形(X=330〜725、Y=265〜630)を除外し、normalまたは対象画像のアルファが32超である領域を対象とした。白背景へ合成したRGB各画素の絶対差平均が35超であれば「変更」とし、変更画素数／対象画素数を百分率化。マスクIoUはジム0.9517〜0.9792、私服0.9727〜0.9830。

**解釈**：ジムはnormalとの差が大きく、特にthinking/surprised/playfulは髪・衣装・姿勢の再描画による差を疑う必要がある。私服も9〜13%程度の表情領域外差があり、原画像の「顔パーツ以外を保持する」厳密な部分編集方式とは断定できない。ただし色味・陰影・非可逆WebPも差分へ寄与するため、この率だけで自動不合格としない。

## 4. 眼・花飾りの相対位置（参考指標であり、正式顔アンカーではない）

顔付近の紫色画素の重心を左右眼の定義済みROI内で算出する画像診断。**瞳の色の重心であり、基準JSONが求める「目の外形中心」ではない**。まぶたの開閉、視線、塗りの変更だけでも変動する。花飾りの重心も色領域からの推定であり厳密な中心座標ではない。

特にジムの`normal`に対して、左眼の紫色重心Yは`thinking +23.7px`、`surprised +15.5px`、`playful +24.6px`。右眼はそれぞれ約`+18.8px`、`+14.1px`、`+11.2px`。花飾りは`thinking`がY約`+17.6px`で、頭部全体の絵の位置や形の変化を疑わせる。

私服5表情の紫色眼重心・花飾りはジムより安定し、同衣装での顔の見た目の揺れは相対的に小さい。**ただし独立に眼の外形と顎を注釈した結果がないのでv2の±6px／±8px案による合否は判定不能。**

ジムと私服を同じ表情で比較すると、`normal`と`smile`の眼重心Y差は小さいが、`thinking`・`surprised`・`playful`では大きい。私服でだけCSS補正を増やすのではなく、まず素材の頭部アンカーを確認する方が合理的。
