- **中心体験：** 栞が「目の前のプレイヤー」に自分から話しかける。地の文・主人公の独白・通常セリフは表示しない。選択肢だけ必要に応じて表示する。
- **想定長：** 会話パート約4〜6分程度を目標（実際の読了時間は未計測）。

## 表記ルール

- **【表示：？？？／朝倉 栞】**：名前欄。正体判明前は `？？？`、主人公が名前を当てて栞が肯定した直後から `朝倉 栞`。試作実装は固定名なので本編用の追加調整が必要。
- **栞「……」**：プレイヤーに表示するセリフ。なるべく一画面1〜2文、短文に分割。
- **口調の転換（v1.1）**：再会が確定するまでは初対面のジム利用者として、自然で硬すぎない敬語で話す。見覚えを感じても勝手に馴れ馴れしくしない。主人公が名前を呼び本人と確認できた瞬間に、昔の幼馴染らしいタメ口へ戻る。以降のセリフは従来どおり。
- **［演出］**：プレイヤーにテキスト表示しない演出指示。立ち絵・背景・画像・位置・間・無言反応など。
- **［操作］**：選択肢、タップ、進行制御。選択肢の文面はプレイヤーに表示する。
- **差分指定**：`normal`は既存のジム立ち絵。他の`thinking / surprised / smile / playful`は**未制作・制作候補**。仮実装ではすべて`normal`に代替する。目線移動・手振りを画像なしで実現できるとは扱わない。
- **動き**：既存Monogatari試作の登場・退場・位置移動・小さな接近・傾き・待機・選択肢を主に使用。タイミングは目安であり、タップ中の破綻とAndroidでの見切れを検証して調整する。
- **時間・場所**：すべてジム。場面転換のために`gym-day`等を使えても、現実のユーザーの来館記録・曜日・時間帯を物語条件とみなさない。

## CUT 00｜見かける人（導入、無言・約5〜8秒）

**背景：ジム／立ち絵：通常／名前欄とセリフ欄は非表示**

1. ［演出］ジム背景から開始。栞がやや離れた位置に一瞬現れ、画面外へ。カメラは主人公の視点。大きなモーションは不要。
2. ［演出］短く暗転、同じジムの別の場面へ。栞が再び視界に入る。短い間を置き、こちらに見覚えがあるような一瞬の停止。
3. ［演出］栞の視線が画面下（バッグ／キーホルダーの方向）へ向くような構図。**視線そのもののアニメーションは差分素材ができるまで実装しない**。キーホルダー画像があれば0.8〜1.2秒ほどインサート表示。画像がなければ「気づいたように動きを止める」演出だけにし、後の会話で情報を補う。
4. ［演出］栞が考え込むように小さく間を取り、そのまま退場。暗転して本編の会話へ。

**狙い：** 「以前から同じジムで見かけていた」「栞の側も見覚えを感じていた」「キーホルダーがきっかけ」の3点を無言で暗示する。時間経過の字幕は使わない。長い導入でプレイヤーを待たせない。

## CUT 01｜話しかけられる

**背景：ジム／立ち絵：通常／名前欄：？？？**

［演出］栞が正面へ近づいて登場。少し迷ってから声をかける。人物のサイズは既存の試作基準を維持。

- 栞「……あの」
- ［間：250ms。主人公が顔を上げた体裁で栞がこちらを見る］
- 栞「すみません。今、ちょっといいですか？」
- ［間：主人公の無言の応答を待つ。固定の主人公セリフは表示しない］
- 栞「ありがとうございます。少し気になったことがあって……」
- ［演出］栞の意識が画面下、バッグの方へ向く。未制作の視線差分を必須にしない。
- 栞「そのバッグについてるキーホルダー……」
- 栞「あのゲームのキャラクターですよね？」
- ［間：350ms］
- 栞「あ、やっぱり！」
- 栞「懐かしいな。私も昔、よく遊んでたんです」
- 栞「それ、限定版ですよね？ なかなか見かけなくて」
- ［演出：表情`thinking`候補。なければ通常＋控えめな傾き］
- 栞「あの、それって昔から持ってるんですか？」
- ［間：450ms。無言の肯定］
- 栞「そうなんですね……」
- 栞「あの、変なこと聞いてもいいですか？」
- 栞「それって、誰かにもらったものだったりしますか？」
- ［間：600ms。主人公が昔友達からもらったことを、表情・うなずき等で伝えた体裁。**実際に主人公の答えを確実に伝える必要があれば、正式実装時に短い選択肢へ変更可能**］
- 栞「……えっ」
- 栞「あ、ごめんなさい。ちょっとびっくりしちゃって……」

**演技の核：** 「見知らぬジム利用者へ礼儀正しく声をかける女の子」から「まさか本人かもしれないと思い始める栞」への変化。見覚えが増しても、確認できるまでは敬語を保つ。動きは少なめ。

## CUT 02｜もしかして

**背景：同じジム／名前欄：？？？**

- ［演出：栞が一歩引くような小さな後退。間：450ms］
- 栞「もしかしたら、すごい勘違いかもしれないんですけど……」
- 栞「私たち、昔どこかで会ったこと、ありませんか？」
- ［間：600ms。主人公の反応を待つ］
- 栞「実は、前からちょっと見覚えがある気がして……」
- 栞「でも、まさかこんなところでって思ってたんです」
- 栞「それで、前にそのキーホルダーを見かけて……」
- 栞「小学生の頃、一緒にゲームしてた子がいたんです」
- 栞「その子も、このキャラクターがすごく好きで」
- ［演出：`thinking`。短い沈黙。正面に戻る］
- 栞「……あの、もしかして。私のこと、覚えてませんか？」

### 選択肢 C01｜名前に気づく

**画面に表示する選択肢（主人公の通常セリフではない）**

- **A「……栞？」** → 栞「……！」／栞「そう！」
- **B「……朝倉？」** → 栞「……！ うん！」／栞「そう、朝倉栞！」

**合流後**

［演出：名前欄を `？？？` → `朝倉 栞` に切り替える。`surprised` → `smile` は素材があれば使用。なければ一瞬静止→軽く接近→通常立ち絵で代替。］

- 栞「久しぶり！ 元気してた？」
- 栞「よかったー！ 人違いだったらどうしようかと思った」
- 栞「だって、こんなところで会うなんて思わないでしょ？」
- ［間：400ms。栞がプレイヤーの反応を見て首を傾げる］
- 栞「……ん？ どうしたの？」
- 栞「あ、もしかして、全然気づいてなかった？」
- ［間：250ms］
- 栞「そっか。まあ、そうだよね」
- 栞「私もあのキーホルダーがなかったら、声かけられなかったと思うし」

**演技の核：** 名前を呼ばれ本人だと確かめた瞬間に、驚きと笑顔に加えて敬語から昔のタメ口に切り替わる。「可愛くなった」等の主人公の感想は台詞や独白にせず、栞がこちらの視線を不思議がる反応で表現。

## CUT 03｜変わらないところ

**背景：同じジム／名前欄：朝倉 栞**

- ［演出：距離を元に戻し、通常の会話のテンポへ］
- 栞「それにしても、そのキーホルダー……」
- 栞「私があげたやつだよね？」
- ［間：450ms。主人公の肯定］
- 栞「うん。やっぱり」
- 栞「それ、まだ使ってくれてたんだね」
- 栞「当時もそのキャラばっかり使ってたよね」
- 栞「今も好きなの？」
- ［間：主人公の肯定。ここは好きなキャラクターだから使っている、という正式設定と一致させる］
- ［演出：`smile`候補。小さく身を乗り出す演出は素材に合わせて控えめに］
- 栞「そっか。変わらないね」
- 栞「……なんか、ちょっと嬉しいな」
- 栞「でも、ずいぶん長持ちしてるね」
- 栞「ちょっと傷ついてるけど」
- ［間：300ms］
- 栞「そういえば、引っ越してから全然会わなくなっちゃったよね」
- 栞「あれからどうしてたの？」
- ［演出：プレイヤーの無言の返答を待つ長めの間。ただし聞いた内容を無制限に知っているような後続セリフにしない］
- 栞「へえ、そうなんだ」
- 栞「……え、今この辺に住んでるの？」
- ［間：肯定を待つ］
- 栞「私も！ 最近、一人暮らしを始めたんだ」
- 栞「ここ、家から歩いて5分くらいなの」
- 栞「すごい偶然だね。まさかこんなところで会うなんて」
- ［演出：自然な笑顔→通常へ］
- 栞「あ、そうだ。私、まだトレーニングの途中だった」
- 栞「危ない危ない。すっかり話し込んじゃった」
- 栞「……でも、久しぶりに会えてよかった」
- 栞「実は最近、ジムに来るのがなかなか続かなくて」
- 栞「近いから大丈夫だと思ってたんだけどね」
- ［間：200ms。困ったように笑う雰囲気。素材がなければ通常立ち絵］
- 栞「意外と難しいんだよね、これが」
- 栞「……あ、そうなんだ」
- 栞「じゃあ、似たような感じなのかな」
- 栞「まあ、今日は二人とも来られたってことで」
- 栞「それでいいんじゃないかな」

**注意：** 最後の「似たような感じ」は、主人公も再開直後であるという原作内部の反応を受けた**このイベント固有の会話**。実際のユーザーのトレーニング履歴と結びつけない。ユーザーの回答を必須にする場合は短い任意選択肢へ置き換える。

### 選択肢 C02｜また会ったとき

- **A「もちろん」** → 栞「よかった。じゃあ、また見かけたら声かけるね」
- **B「またジムで会おう」** → 栞「うん。見かけたら声かけるね」

**合流後**

- ［演出：`playful`候補。未制作なら通常＋控えめな傾き］
- 栞「……今度は、そっちから気づいてくれてもいいんだよ？」
- ［演出：小さな笑みの間、立ち絵が自然に離れフェードアウト。背景はジムのまま、短く暗転］
- ［操作：イベント完走。呼び出し元のイベント画面へ復帰。必要なら「第1話終了」を小さく表示、**地の文としては出さない**］

## 素材・技術の受け渡し

| 対象 | v1の要件 | 現状 |
|---|---|---|
| ジム背景 | 既存の昼／夜背景から場面に合うものを固定利用 | **既存素材あり** |
| ジム立ち絵 `normal` | 現行サイズ基準を維持 | **既存1枚あり** |
| `thinking` | 思い当たる・迷う表情 | **新規候補** |
| `surprised` | 名前が判明した瞬間 | **新規候補** |
| `smile` | 再会の喜び・キーホルダーの話 | **新規候補** |
| `playful` | 最後の控えめないたずら | **任意／後回し可** |
| キーホルダーのアップ | 初回に見つけたと分かる短い小道具カット | **未制作。なければCUT 00の一部を省略して台詞で補う** |
| 名前欄切替 | 正体判明前「？？？」、判明後「朝倉 栞」 | **現在の試作は固定名。実装調整が必要** |
| 選択肢 C01 / C02 | 2択各1回。分岐後に共通パートへ合流 | **Monogatari試作にChoice/jumpあり。実装接続は未実施** |
| 進行・既読・再閲覧 | 初回イベント・明示的な再閲覧を分ける | **本編用は未実装。保存先・条件はアプリ開発で設計** |

### 表示とデータについて

- セリフだけをゲーム画面に表示し、演出指示や原作の主人公モノローグは表示しない。
- 原作6場面を、短い無言導入＋4つの会話CUTに再編。CUTは内部制作単位であり字幕や場面タイトルとしては表示しない。
- 立ち絵1枚による仮実装は可能だが、**表情差分なしの動きで「目を伏せる」「視線を移す」「笑う」を再現できたことにはしない**。
- 既存Monogatari試作はiframe内で本編とは独立している。正式導入の際は既存UIとの共存、戻る・連打・省モーション・ブラウザ履歴・画像位置を回帰確認する。
- キーホルダーのゲーム名・キャラクター名・デザインは正式未決定。勝手に固有名詞や色・贈答事情を確定しない。
- ユーザーの個人的な会話履歴や筋トレ記録を公開GitHubへ保存しない。ストーリー進行を保存する場合はD1等の既存方針に従う。
- 現在の `docs/monogatari-prototype.md` は比較試作の記録。ユーザーのMonogatari採用判断を反映した本編仕様・実装検証は別工程とする。
