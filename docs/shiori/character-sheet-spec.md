## 1. 目的と参照順序

朝倉栞の**標準私服、身長・体型、正面／側面／背面の整合性、喜怒哀楽の表情4種**を固定し、ホーム立ち絵・衣装差分制作の参照元となるキャラクターシートを制作する。

制作前に必ず次を最新 `main` から確認する。

1. [character.md](./character.md)：性格・人物像・確定した身体設定
2. [visual.md](./visual.md)：外見・制作方針
3. [dialogue.md](./dialogue.md)：表情の解釈に関係する口調・キャラクター性
4. [reference/shiori-master-v1.jpg](./reference/shiori-master-v1.jpg)：**顔・目・髪・表情・同一人物性の最優先基準**
5. [reference/shiori-style-fullbody-v1.jpg](./reference/shiori-style-fullbody-v1.jpg)：**アニメ調の色面、水彩の透明感、光・全身の空気感、花飾り**

## 2. シート構成・レイアウト

- **横長の1枚のキャラクター設定シート**。三面図を大きく、表情・ディテール・カラーパレットを補助枠にまとめる。
- **主領域：正面・側面・背面の3つの全身図**。同じ人物・衣装・靴・縮尺で統一。頭頂と足先を揃え、原則自然な直立姿勢。原則同じ背景・均等な照明にする。
- **補助領域：喜・怒・哀・楽の顔アップ4種**。目・口・眉の違いが分かるサイズで配置し、顔つきが別人にならないようにする。
- **ディテール：片側の花飾り、前髪・横髪・後頭部、衣装の構造が確認できる拡大図**。
- **カラーパレット：髪・瞳・肌・服・花飾り**。RGB/HEX値は作品から確認後に定め、現段階で推測の数値を「確定値」としない。
- テキスト見出し：朝倉 栞 / Shiori Asakura、約160cm、FRONT/SIDE/BACK、喜/怒/哀/楽。読めない細字や余分な装飾は避ける。
- キャラクターシートは**制作資料**なので、背景透過は必須ではない。明るく中立的な背景で形状を読み取りやすくする。

### 三面図ごとの重点

| 視点 | 固定する情報 |
|---|---|
| 正面 | 頭身・体型・顔・前髪・花飾り・トップス・スカート丈・靴 |
| 側面 | 横顔・後頭部・ボブの厚み・胴体の自然な線・衣服の重なりとスカートの広がり |
| 背面 | ボブの後ろ姿・花飾りの取り付け位置・カーディガンとスカートの背面構造 |

**側面・背面で体型、衣装、髪の長さ、花飾りの左右が変化してはいけない。** 三面図を別衣装・別人物の集合にしない。

## 3. 身長・体型（確定）

| 項目 | 基準 |
|---|---|
| 身長 | **約160cm**（従来の164cm案は撤回） |
| 全体の細さ | **2/4：やや細身** |
| 胸の印象 | **2〜3/4：やや控えめ〜標準** |
| 脚の印象 | **2/3：やや長め** |
| 肩幅 | やや華奢 |
| ウエスト | 自然なくびれ |
| 頭身 | **7頭身前後を起点に調整**（目安であり厳密な数値は未決定） |

全体としてすらっと上品だが、華奢すぎず自然な女性らしい柔らかさがある。身長160cmのバランスを保ち、過度な脚長化・誇張された胸や腰・幼児的な体型は避ける。健康的だが過度にスポーティにしない。

## 4. v1標準私服（確定した方向性）

**基準絵その2の服装を踏襲した私服A案**を採用する。

- 白系のシンプルなインナー
- 淡いラベンダーのカーディガン
- 淡く上品な花柄の**ミモレ〜ロング丈スカート**
- 落ち着いた、少しフェミニンな綺麗めカジュアル
- 小さな**白〜薄紫の花飾り**を片側の髪につける
- 靴は私服に合うシンプルなものを採用する。**具体的な靴の型・アクセサリー細部はシート制作時の検討事項**であり、未確定を隠さない。

三面図では同一の服装デザインを完全に一致させる。過剰な露出、ギャル風、装飾過多、コスプレ風、色気の強調を避ける。

## 5. 顔・髪型・花飾り

- 顔は美人寄り、上品で親しみやすい。**顔基準その1と同一人物**であることを優先する。
- 肩に触れる程度の**ダークブラウンのボブ**。自然な毛束感、シースルーバング、軽い内巻き・外ハネ。
- **ラベンダー系の紫の瞳**、やや切れ長で穏やかなツリ目。
- 心から笑うと**小さな八重歯**が見える。
- 花飾りは**小ぶり・白〜薄紫・片側だけ**。飾りが髪型や顔を隠さない。
- 花飾りの取り付け側、前後から見た位置関係を統一する。細部の形は基準絵その2を参考に調整する。

## 6. 喜怒哀楽の4表情

| 表情 | 具体像 | 避けたい表現 |
|---|---|---|
| **喜** | 心から嬉しい**無邪気な笑顔**。目元も柔らかく崩れ、小さな八重歯が見える | 作り笑いや不自然に過剰な笑顔 |
| **怒** | 軽くむっとした**控えめな不機嫌顔**。眉・口元に軽い不満 | 恐ろしい激怒、攻撃的な罵倒顔 |
| **哀** | 目元に陰りのある**静かな悲しみ**。普段の余裕が少し消える | 大泣き・過剰な絶望の演技 |
| **楽** | 目を少し細め、相手の反応を楽しむ**いたずらっぽい笑み**（小悪魔感2/5） | 誘惑的な流し目・過剰な色気 |

**「喜」と「楽」を同じ笑顔にしない。** 喜は純粋な嬉しさ、楽は遊び心。いずれも顔基準その1を優先し、別人の顔にならないようにする。

## 7. 画風と技術的品質

- **アニメ調の明快な色面・セル塗りを土台**にする。
- **水彩のような淡いにじみ・透明感・柔らかな光**を重ねる。
- 彩度を強くしすぎず、ラベンダー・白・柔らかな中間色を中心にする。
- 不自然なCG光沢、描き込み過多、ベタベタしたハイライト、過剰な発光は避ける。
- 三面図では演出的な逆光よりも**ディテールが確認できる中立的な明るさ**を優先する。
- 三面図は同縮尺、足元まで描き切る。手指の本数、関節、左右の一致、花飾り・衣装柄の連続性を検査する。
- 文字は少なく判読可能に。生成結果の細かい文字が不正確な場合は**画像編集で後付けする**ことも検討する。
