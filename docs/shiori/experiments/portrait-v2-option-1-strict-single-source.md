# 比較試験・案1｜旧v2厳密固定方式（口元だけ変更）

> **試験用・未採用**。旧PR #28で良い結果が得られた、一枚の基準画像を強く固定する方式を別資料として保存する。既存のv2標準やアプリに適用しない。画像の実制作にはユーザーの明示的な「生成」指示が必要。

## 目的と適用

同一衣装・同一ポーズ・同一構図の既存立ち絵から、**指定した顔パーツだけ**を変えた差分を作る。今回の公平な比較課題は「大きく開いた笑顔 → 口を少し閉じた自然な微笑み」で、**口元以外を変更しない**。

原則として元画像1枚を主参照にする。本人性の確認にはGitHubの正式人物資料を使うが、既存の服やポーズを別の基準画像へ寄せない。

## 制作向け指示文：案1

```text
添付した1086×1448pxの朝倉栞の画像を唯一の編集原本として、
口元の表情だけを変更した立ち絵を1枚制作する。

大きく開いた笑顔を、口を少し閉じた自然な微笑みにする。
今回変更するのは口元だけ。目・眉・頬・顎・顔輪郭・髪・
花飾り・首・手・肩・身体・衣装・装飾・照明は変更しない。

元画像のカメラ位置・顔の座標・顔の傾き・大きさ・目の位置を固定し、
可能な限り元の画素・輪郭を保持する。
両眼中心と顎先の位置も原画像と一致させるよう指示する。
元画像の意図的な見切れを保持し、再構図・トリミング・拡大縮小しない。

1086×1448pxの透過PNGを原本とする。文字・背景・UIは追加しない。
```

## 検品

- 技術：1086×1448、PNG、実アルファ、読み取り可能。
- 同一元画像との**比較診断**：眼・顎・髪・花飾り・衣装・手・肩・外形に望まない差がないか画像重ね合わせ／画素差分／輪郭目視を行う。
- 数値の座標差・非顔領域の差分率は**参考診断**とする。画像編集モデルに完全画素保持を保証させることはできず、解析値だけで人物品質を認定しない。
- 表情：口を閉じすぎず、栞の自然な微笑みを実現しているか確認。

本資料は特定の「口元のみ変更」試験用。驚きの開眼・頬・顎が自然に動く複合的な表情変更へ、固定要求を一律拡張しない。

## 比較の統制

案2と同じ元画像、同じ目的、同じサイズ・透明仕様、同じ出力枚数を使う。ユーザーが比較対象を指定するまで元画像を勝手に変更しない。両案の入力に使った実画像ファイル・SHAとツールへの入力成否を記録する。正式採用・登録・マージは禁止。
