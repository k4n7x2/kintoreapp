# 朝倉栞｜表情差分 A/B 比較実験の条件（いずれも未採用）

- **案1**：[旧v2の厳密固定・単一原本方式](portrait-v2-option-1-strict-single-source.md)
- **案2**：[新規と差分を分離した制作ルール方式](portrait-v2-option-2-split-workflows.md)

2案は**競合する試験案**として保持。今回の比較が終わるまで既存の`home-portrait-v2-generation-rules.md`、正式人物設定、画像、CSS、mainを上書きしない。画像制作はユーザーが明示的に「生成」と依頼した場合だけ実行する。

## 同一条件

1. **完全に同じ1086×1448の元画像1枚**を使用。入力成功と実ファイルSHAを確認。参照画像の片方だけを差し替えることはしない。
2. **同じ指示内容**：「大きく開いた笑顔 → 口を少し閉じた自然な微笑み」。他部位は変更対象外。
3. 透過PNG原本、同じ縦横サイズ、同じ画角・見切れ。**同じ制作ツール、同じ品質設定、同じ出力枚数**。各案1枚から比較し、偶然性を調べる場合はそれぞれ3回ずつ。
4. 案1だけが「両眼中点・顎先の座標固定を明記、強い保存と差分計測を要求」、案2は「制作時の保持指示・目視重視で、数値固定を要求しない」。**変更点をここに限定して比較する**。
5. 差分画像を後処理で片方だけ整列・補正・切り抜きしない。

## 判定表（同一ルーブリック）

| 指標 | 0点 | 1点 | 2点 |
|---|---|---|---|
| 口元の指示再現 | 変更なし／別表情 | 部分的に達成 | 自然な小さな微笑み |
| 不要な顔全体の変化 | 明確な別人化 | 軽い輪郭／目の変動 | 元の顔を維持 |
| 髪・花飾り・身体・衣装の保持 | 目立つ描き直し | 軽い変化 | ほぼ保持 |
| 表情切替の自然さ | 明らかな位置飛び | 小さな違和感 | 自然 |
| 技術仕様 | 寸法／透過の失敗 | 部分的不備 | 完全に満たす |

合計10点、ただし**技術仕様で0点なら比較参考扱いで採用しない**。客観指標として元画像との画素差分（口元を除く領域）を両方に対して同じ閾値・方法で取得してもよい。**差分率が小さい＝必ず美しい／本人に似る、ではない**ため、点数とは別に診断データとして示す。必要であればAndroid上で2枚を同じ条件で切り替えて評価する。
