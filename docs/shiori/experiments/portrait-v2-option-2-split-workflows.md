# 比較試験・案2｜新規制作／表情差分を分けた制作ルール方式

> **試験用・未採用**。案1と別文書で比較する。画像制作・編集はユーザーの明示的な「生成」依頼がある場合のみ。既存のv2標準やアプリの挙動を変更しない。

## 適用先による2経路

### 新規のホーム立ち絵・衣装差分

- 私服5表情セットを構図・顔の見かけの大きさ・表情可動域の制作参考にする。通常表情 `normal` が代表。
- 人物の正式参照3枚（顔・塗り・体型）と、衣装固有の参照を用途別に使う。
- 1086×1448、実アルファ透過、通常ホーム用の近接感は固定。顔のピクセル座標を一律に強制一致させない。
- 新規画像に基準原本ができたら、以降の**同一衣装の表情差分では新規制作ルールで描き直さず、次の差分経路に切り替える。**

### 既存立ち絵からの表情差分

- **変更の主参照は既存画像1枚。** 私服5枚を追加で混ぜて服や髪を描き直さない。
- 差分対象と変更禁止部位を具体的に宣言する。
- 顔の画角と見かけの大きさ、髪・花飾り・手・肩・衣装などの描画継続を強く指示。ただし目・顎等のピクセル座標は合否の固定閾値にしない。
- 表情が自然で、画面切替時に頭全体が不自然に跳ねないことを目視で判定する。

## 制作向け指示文：案2（案1と同じ「口元のみ」試験）

```text
添付した1086×1448pxの朝倉栞を、今回の差分の唯一の編集原本とする。
大きく開いた笑顔を、口を少し閉じた自然な微笑みに変更する。

口元以外は編集対象ではない。目・眉・頬・顎・顔輪郭・髪・
花飾り・首・手・肩・身体・衣装・装飾・照明を描き直さず、
元画像の構図・カメラ距離・顔の見かけの大きさ・向きを保つ。

自然な微笑みを優先し、目や顎の座標を数値に強制一致させる処理はしない。
ただし今回は口元のみの変更なので、顔全体や服・ポーズの位置変化は避ける。
頭部が表情切替時に不自然に跳ばないようにする。

1086×1448pxの透過PNGを原本とする。
文字・背景・UIは追加しない。元画像の自然な見切れも保つ。
```

## 検品

- 技術：1086×1448、PNG、実アルファ、読み取り可能。
- 目視：元画像の髪・衣装・花飾り・目・顔輪郭・肩・手が意図せず変わっていないか、口元だけが指定どおり変わったか。
- 画像差分は診断資料として表示できるが、顔アンカー数値による自動合否は適用しない。
- 表情の自然さと、同一枠の切替時の違和感を評価する。実機検査していなければ未確認。

## 比較の統制

案1と同じ元画像・同じ口元変更・同じキャンバス・同じ出力枚数を使う。提案した画像を正式基準へ自動追加しない。既存画像・CSS・main・本番には影響を与えない。
