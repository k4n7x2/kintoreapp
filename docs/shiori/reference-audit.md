## 正式採用との境界

今回の資料整備では、画像の生成・加工・正式画像の置換は行っていない。PNG3枚をJPEG3枚の「同一版の複製」として無条件に扱わない。

PNGの修正版を正式採用する場合は、ユーザーの採用指示に基づいて旧画像を残し、別バージョンで登録する。そのうえで `README.md`、`visual.md`、関連する仕様書の現行参照を更新する。形式は実ファイルに合わせ、拡張子だけを変更しない。
