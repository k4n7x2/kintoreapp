## 実装経路

| 機能 | 根拠・範囲 |
|---|---|
| 4画面 | `public/index.html` の `data-page` と `public/app.js` の `setScreen`。ホーム・記録・履歴・設定 |
| 認証 | `src/index.js` のlogin/session/logout、フロントの `setAuthenticated` |

| 削除 | UI確認ダイアログ後にDELETE。同日複数レコードは別ID |
| カレンダー | 履歴画面。日付タップで記録画面へ。ホームには存在しない |
| 設定 | ログアウトと接続状態表示。ユーザー設定の永続保存はない |
| キャラクター領域 | ホームにトレーニング衣装の透過WebP立ち絵を配置。記録・履歴・設定は空レイヤー。セリフ表示は未接続 |

| セリフ候補 | greetingsは30件、login-dialoguesは14件。現行JSからのfetchや抽選処理なし |
| セット | `workout_sets` のDDLのみ。操作APIと入力UIなし |
