## ホーム配置のプロトタイプ

従来の`86e0f19`で顔の視線位置を調整し、後続でホームの表示倍率を通常`scale(1.14)`、幅380px以下`scale(1.159)`、高さ640px以下`scale(1.064)`へ変更した。右下起点、左メニュー位置52%、上部の吹き出し、下端フェードなしを維持する。

部屋着テスト画像は縦長（941×1672）のため、トレーニング衣装（800×1067）と同じ下端位置では頭部が高く見えた。衣装選択を操作面の`data-outfit`へ反映し、部屋着のみ`bottom: calc(-1 * min(38vw, 160px))`で下へ移す。Android幅393px相当で約149 CSS pxのオフセット。

**2026-10-16の追加調整：衣装間で見かけの大きさも統一する。** トレーニング衣装を表示サイズ・顔位置の基準として維持。提供された同一端末・同一背景のスクリーンショット2枚の顔周辺を比較した結果、部屋着の顔は約12%小さいため、部屋着の表示倍率を通常`1.276`（基準`1.14`の約1.12倍）、幅380px以下`1.297`（基準`1.159`）、高さ640px以下`1.191`（基準`1.064`）とする。拡大起点を通常`72% 55%`、低い画面では`62% 39%`へ設定し、顔周辺を合わせて頭頂と吹き出しの干渉を抑える。

**2026-10-16にユーザーが表示を確認し、現在のサイズ感・距離感を今後も維持する方針を採用した。** 再現基準はPR #11マージ後のmain `5b8d16ce23eab0ec188d69b2d5e33ea5923a4018` の2画像・CSS・JS。現状の倍率は**この2素材固有**であり、新しい衣装・表情画像には同倍率を一律適用しない。今後は`docs/shiori/visual.md`第8.2.1節に従い、頭部の見かけの高さ・両目中点・吹き出しとメニューの干渉を同条件で照合して、画像ごとに等方倍率・起点・オフセットを設定する。**基準としての見た目は採用済み**だが、すべての画面寸法での数値一致や自動顔検出は未実装・未検証。画像・吹き出し・メニュー・タップ演出そのものを今回変更するものではない。
